I build perception software that turns imperfect sensor observations into useful geometry for robots.

Currently a **Perception Algorithm Engineer in consumer robotics**, working on multi-sensor perception systems led by stereo or LiDAR observations. My work spans geometric reasoning, model post-processing, temporal consistency and efficient C++ implementation.

M.Sc. in **Robotic Systems Engineering · RWTH Aachen University**.

### Selected contributions

- **[Stereo perception](https://hyandnn.github.io/projects/stereo.html)** — addressed sparse observations of thin obstacles through complementary geometric and semantic evidence; also worked on ground, floor surfaces and runtime optimization.
- **[LiDAR perception](https://hyandnn.github.io/projects/lidar.html)** — led tracking integration in an established system, with implementation, maintenance and deployment fixes for height structure and overhanging obstacles.
- **[Physics simulation](https://hyandnn.github.io/projects/collision.html)** — integrated SAP, a BVH midphase and GJK alongside an engine’s existing collision-detection options.
- **[Vision-based motion analysis](https://hyandnn.github.io/projects/motion.html)** — aligned climbing-video frames to a common wall reference for trajectory and movement analysis.
